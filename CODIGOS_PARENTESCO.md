# Códigos Oficiales de Parentesco (SES.Hospedajes)

Según las instrucciones v1.2.0 del Ministerio del Interior para el alta masiva de comunicaciones.

## 8.3. RELACIÓN DE PARENTESCO

| Código | Descripción |
|--------|-------------|
| AB | Abuelo/a |
| BA | Bisabuelo/a |
| BN | Bisnieto/a |
| CD | Cuñado/a |
| CY | Cónyuge |
| HJ | Hijo/a |
| HR | Hermano/a |
| NI | Nieto/a |
| PM | Padre o madre |
| SB | Sobrino/a |
| SG | Suegro/a |
| TI | Tío/a |
| YN | Yerno o nuera |
| TU | Tutor/a |
| OT | Otro |

**Nota importante:** Según el Real Decreto 933/2021 y la normativa vigente, el parentesco **SOLO es obligatorio cuando hay menores de edad** acompañantes. Para adultos NO es obligatorio indicar parentesco.
